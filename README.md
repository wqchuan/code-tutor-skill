# Code Tutor

一个面向编程初学者的中文 Codex Skill，让“这段代码到底在做什么”变得简短、具体、容易验证。

## 它能做什么

- 当用户只发送源代码或配置片段、没有附带任务说明时，自动进入代码讲解模式。
- 第一次讲解固定说明：做什么、输入什么、输出什么、一个最小输入/输出示例，以及逐行解释。
- 当用户再次发送前面代码中的一小段时，进一步解释这段代码涉及的库、函数、执行顺序和实际作用。
- 默认只读：不会擅自修改、运行、测试或优化代码。
- 信息不足时明确说明无法确认，不猜测代码片段之外的业务逻辑。

## 适合谁

适合刚开始学习 Python 或其他编程语言，希望快速理解代码作用、数据输入输出和每一行含义的人。

## 安装

将本目录复制到用户级 Skill 目录：

```text
~/.agents/skills/code-tutor/
```

确保目录中至少包含：

```text
code-tutor/
└── SKILL.md
```

重启 Codex 后，可以通过 `$code-tutor` 显式调用；直接发送一段没有提示词的源代码时，也可以自动触发。

## 首次讲解格式

```text
做什么
输入什么
输出什么
小例子
逐行解释
```

“小例子”会使用一组具体输入展示对应输出，但不会自动执行代码。代码片段不完整时，Skill 会说明缺少哪些信息，而不是编造结果。
